# パレットの通し仕様

`⌘K`（Windows / Linux は `Ctrl+K`）で Backlog のページに重なる 1 面。この文書は
**状態 → 並ぶ行 → 押したときに起きること**を通しで定める。画面の絵ではなく操作の契約として読む。

用語: **行** = リストの 1 項目。**セクション** = 見出しつきの行のまとまり。**スコープパス** = 入力欄の左に積まれる
`nulab / Webリニューアル /` の階層。**候補** = ローカル索引から同期的に出る行。**検索結果** = API から非同期に届く行。

---

## 1. 面の構造

```
┌─ ヘッダー ────────────────────────────────────────────────┐
│ 🔍 [nulab / Webリニューアル /] 入力▍ゴースト補完      esc 閉じる │
├─ リスト（スクロール可、最大高さは可変） ───────────────────┤
│ セクション見出し                                    補足   │
│ 行 ×n                                                    │
├─ フッター ────────────────────────────────────────────────┤
│ ↵ 開く  ↑↓ 移動  ⌫ 1 段戻す  ⇥ 補完            トースト／銘 │
└──────────────────────────────────────────────────────────┘
```

| 部位 | 決定 |
|---|---|
| 幅 | `min(640px, ビューポート幅 − 32px)`。寸法はトークンで持ち、コンポーネントに数値を直書きしない |
| 位置 | 水平中央、上端からビューポート高さの 12〜15% |
| リストの高さ | 行数に応じて伸び、上限はビューポート高さの 60%。超えたらリスト内スクロール。0 行のときは 1 行分の高さに縮む |
| 背景 | ビューポート全面の薄い暗転。暗転部分のクリックで閉じる（P7） |
| ヘッダー | スコープパス → 入力欄（ゴースト補完つき）→ `esc` ヒント。⌫ の 1 回目には「もう一度 ⌫ で右端を削除」の予告が **`esc` ヒントの位置に入れ替わりで**出る（行を足さない。高さが変わるとレイアウトシフトになる） |
| フッター | 左からキーヒント（§6 の優先順）、右端はトースト（§11）、トーストが無ければ「Backlog Palette」 |

---

## 2. 状態モデル

パレットの状態は次の 4 つに集約される。UI（presenter）はこれを描くだけで、遷移は container が持つ。

```
stack:   { segments: Segment[]; armedForDelete: boolean }   // §8
input:   string                                              // 入力欄の文字列（IME 未確定を含む）
session: undefined | { query; spaces: SpaceProgress[]; rows; held: number; done: boolean }   // §7
toast:   undefined | { message; detail? }                    // §11
```

導出されるもの（状態として別に持たない）:

- **スコープ** ← `stack.segments` のうち `space` / `project` セグメント
- **実行中のコマンド** ← `stack.segments` の右端が `command` なら、その引数選択の階層にいる
- **セクション** ← `input` と索引と `session` から同期的に組む（§4）
- **フッターのキーヒント** ← 状態から導出する `KeyBinding[]`（§6・不変条件 I2）

## 3. 開閉

| 操作 | 結果 |
|---|---|
| `⌘K`（閉じているとき） | 開く。入力欄にフォーカスが移り、先頭行が選択される。前回の入力は残さない |
| `⌘K`（開いているとき） | 閉じる（D-8） |
| `Esc`（スコープだけのとき） | 閉じる |
| `Esc`（コマンド階層のとき） | 右端の 1 段を外す。閉じない（§8） |
| 暗転部分をクリック | 閉じる |
| 行の動作で遷移した | 閉じる。コピーは例外（§11） |
| ページが遷移した | 閉じる |

- 開いた直後の表示は **API 応答を待たない**。空状態は表示キャッシュだけで描き、担当課題は届いた時点で末尾に追記する（I4）
- `⌘K` → 表示までの予算 **100ms 以内**（iframe を先行注入して表示だけ切り替える）
- 開いたときのスコープパスは現在ページから決まる: 課題・プロジェクト配下のページなら `[space / project]`、スペース直下なら `[space]`
- **Backlog のページ上だけで効く**（D-10）。他のサイトの `⌘K` を奪わないため、ブラウザの `commands` にキーを登録せず、Backlog のページの content script で捕捉する（`surfaces.md` §3）

## 4. 入力の解釈と並ぶ行

入力は打鍵に**同期して**解釈する。API は叩かない（検索は Enter で明示、§7）。
正規化は 1 箇所で行う: NFKC → カタカナをひらがなへ → 大文字小文字を無視（課題キーの判定だけは原文で）。

| 入力 | 判定 | 並ぶセクション（上から） |
|---|---|---|
| 空 | 空状態 | §9。**根（スペースを積んでいない）では検索行を出さず、スペースの移動と共通ページだけ**（D-20） |
| `PROJ-123`（英大文字始まり + `-` + 数字） | 課題キー | ① **この課題を直接開く**（固定・アクセント） ② 前方一致する課題（索引から、最大 5） ③ 「`PROJ-123` を検索」 |
| `123`（数字のみ、現在プロジェクトがある） | 課題番号 | `{現在のプロジェクトキー}-123` として上と同じ |
| `>語` / `＞語` | コマンドのみ | コマンドの一致（語が空なら全コマンド） |
| `#語` / `＃語` | プロジェクトのみ | プロジェクトの一致（語が空なら全プロジェクト） |
| その他の語 | 自由語 | 強いローカル一致があれば ① 候補 ② 検索行、無ければ ① 検索行 ② 候補（下記）。根では検索行を出さず、スペース名・共通ページ名の照合だけ |
| 一致なし | 自由語 | 検索行だけが残る |

正規化パイプラインには **ローマ字 → かな変換**の段を含める。`kadai` は `かだい` としても照合され、かなの別名を持つ
ページ・コマンドに英字入力で届く。読みを持たない件名・プロジェクト名には効かない。

**候補セクションの構成**（自由語のとき）

| セクション | 中身 | 上限 |
|---|---|---|
| （見出しなし） | 検索行 `「語」を検索` — 課題・Wiki・ドキュメントをスペース横断で | 1 |
| ページ | ページ定義（`backlog-facts.md` §1 の URL を持つもの）、プロジェクト、スペース、表示キャッシュにある課題・Wiki・ドキュメント | 5 |
| コマンド | コピー 4 種（課題ページのときだけ）、スペースを切り替え ›（**スコープが `[space]` のときだけ**。プロジェクトまで積んだ状態や根では出さない） | 5 |

- 全体の上限 12 行。上限で切ったセクションは見出しの補足に「他 N 件」と出す。**切れた行を `›` に化けさせない**（MVP の `hint: 'more'` の流用はやめる）
- 「強いローカル一致」= 前方一致以上。`ぼーど` → ボード が先頭に来て `⌘K` + 語 + `Enter` で着けることが基準
- 各セクション内の並びは 一致の強さ → 現在プロジェクト／スペースの加点 → 頻度・直近性。**セクションの順序は固定**、課題キー完全一致とコマンド名完全一致は個人化で動かない
- **選択の初期位置は常に先頭行。** 入力が変わるたびに先頭へ戻す（変換中の更新も同じ）

## 5. 行のカタログ

すべての行は同じ部品で描く。種別で変わるのはアイコンと Enter の結果だけ。

**表示要素**: 種別アイコン ｜ [種別タグ] [等幅コード] タイトル ｜ [状態マーカー] 補足 ｜ [スペースバッジ] ｜ キーヒント

| kind | 何の行か | 表示 | `↵` | `⌘↵` | `⇥` |
|---|---|---|---|---|---|
| `page` | ページ定義 | タイトル=ページ名、補足=`{プロジェクト名} · ページ` | そのページへ遷移（現在タブ） | 新しいタブで開く | タイトルで補完 |
| `issue` | 課題（キャッシュ・直接ジャンプ・検索結果） | コード=課題キー、補足=`{プロジェクト} · {担当者}`、マーカー=ステータス、タグ=種別 | `/view/{key}` へ遷移 | 新しいタブ | 課題キーで補完 |
| `wiki` / `document` | Wiki・ドキュメント | タイトル、補足=`{プロジェクト} · 最終更新 {人}` | 遷移 | 新しいタブ | タイトルで補完 |
| `project` | プロジェクト | タイトル=プロジェクト名、補足=`プロジェクト · {キー}` | プロジェクトホームへ遷移（D-4） | 新しいタブ | **スコープに積む**（`[space / project]`） |
| `space` | スペース（候補・コマンド階層の引数） | タイトル=表示名（スペース名。キーではない）、補足=ホスト、バッジ=スペースのアイコン画像（無ければ頭文字） | そのスペースのダッシュボードへ遷移 | 新しいタブ | **スコープに積む**（`[space]`） |
| `command` | コピー系 | タイトル=動詞句、補足=対象（課題キー） | 実行してトースト（§11） | 同じ | タイトルで補完 |
| `command` | 2 段階（スペースを切り替え） | 同上、ヒントは `›` | スタックに積み、引数の行を出す（§8） | — | 同じ（積む） |
| `search` | 検索行 | タイトル=`「語」を検索`、補足=`課題・Wiki・ドキュメント · {スコープ名}`、アクセント | 検索を実行（§7） | — | — |
| `connect` | 未接続スペース／接続を促す行 | タイトル=`{space} は未接続 — 接続する`、危険色 | 接続導線へ遷移（`surfaces.md` §1） | — | — |
| `status` | 検索中のスペースの障害 | タイトル=`{space} は認証が切れています — 再接続`、危険色 | 再接続導線へ | — | — |
| `notice` | 保留中の結果の予告 | タイトル=`N 件の新しい結果 — ↑ で先頭へ` | 保留を合流させ、選択を先頭へ | — | — |
| `panel` | 詳細検索へ渡す | タイトル=`詳細検索で条件を変えて探す`、補足=`サイドパネルを開きます` | サイドパネルを開き語とスコープを渡す（`⌘→` と同じ） | — | — |
| `external` | 本体の検索へ逃がす | タイトル=`Backlog の課題検索を開く`、補足=URL | 新しいタブで開く | 同じ | — |
| `hint` | 動作を持たない案内（履歴が無いときなど） | 淡色、ヒント無し | 何も起きない（ヒントを出さない） | — | — |

`⇥` は「実行せずに入力欄へ取り込む」の 1 つの意味で統一する（D-4）。スコープになれる行（`space` `project`）と
階層を持つ行（2 段階 `command`）はスタックに積み、それ以外は入力をタイトルで置き換える。どちらもフォーカスは入力欄に残る。

**共通規則**

- 選択行は 面の反転 + 左端のアクセント罫 + タイトルの太字化 の 3 点で示す
- `tone: accent` の行（直接ジャンプ・検索行・0 件時の先頭提案）は選択・非選択どちらでもアクセント面を敷く
- キーヒントは非選択行でも薄く残す（P5）
- スペースのアイコン（`lib/` が API から取得して data URL で渡す。無ければ頭文字）は `space` 行の先頭とスコープパスに出す。検索はスペースの中だけ（D-20）なので、結果の行にスペースバッジは出ない
- タイトルは 1 行で省略し、`title` 属性に全文を持つ。補足は 1 行で省略。2 行になるのは補足かマーカーがあるときだけ
- 種別 → アイコンの写像は UI の 1 箇所に閉じる。呼び出し側はアイコン名を渡さない
- ステータス・種別の色は Backlog の値ではなく **役割の tone**（`neutral` `info` `success` `done` `warning` `danger`）で渡す。写像は `lib/` が持つ

## 6. キーのカタログ

すべて入力欄にフォーカスがある状態で受ける（仮想フォーカス。↑↓ でフォーカスは動かず `aria-activedescendant` だけが動く）。
**変換中（`isComposing`）のキーはすべて捨てる**（I5）。

| キー | 文脈 | 結果 | フッター表示 |
|---|---|---|---|
| `↓` / `Ctrl+N` | 常時 | 選択を 1 行下へ。末尾で止まる（循環しない）。セクション見出しは飛ばす | `↑↓ 移動`（行が 2 つ以上のとき） |
| `↑` / `Ctrl+P` | 常時 | 選択を 1 行上へ。先頭で止まる。先頭に戻ったとき保留があれば合流（§7.4） | 同上 |
| `↵` | 選択行がある | 選択行の `↵` 動作（§5）。**宛先は DOM 上で選択されている行**、無ければ先頭行 | `↵ 開く`（選択行が動作を持つとき。文言は行による: 開く／検索／適用／接続） |
| `⌘↵` | 選択行が遷移する行 | 新しいタブで開く。パレットは閉じる | `⌘↵ 新しいタブ`（選択行が対応するときだけ） |
| `⇥` | 選択行が `space` / `project` / 2 段階 `command` | 選択行をスタックに積む。入力は空になり、その階層の候補が出る。フォーカスは入力欄に残る | `⇥ スコープに積む`／`⇥ 階層を開く` |
| `⇥` | 選択行がそれ以外で、タイトルを持つ | 選択行のタイトル（課題なら課題キー）で入力を置き換える。フォーカスは入力欄に残る | `⇥ 補完` |
| `⇥` | 取り込める行がない | **何も起きない。フォーカスは出ない**（I3） | 出さない |
| `⇧⇥` | 常時 | 何も起きない。フォーカスは出ない | 出さない |
| `⌫` | キャレットが先頭（`selectionStart === 0 && selectionEnd === 0`）でスタックに外せる段がある | 1 回目: 右端を削除待ち（取り消し線 + 予告）。2 回目: 右端を外す。**入力文字は消えない** | `⌫ 右端から 1 段戻す`／削除待ち中は `⌫ {label} を外す` |
| `⌫` | それ以外 | 通常の 1 文字削除。削除待ちは解除 | 出さない |
| `Esc` | コマンド階層にいる | 右端の 1 段を外す（削除待ちを経ない） | `esc 1 つ前に戻る`（ヘッダー右） |
| `Esc` | それ以外 | 閉じる | `esc 閉じる`（ヘッダー右） |
| `⌘⇧C` | 検索結果が出ている | 検索状態の URL をコピーしてトースト（§7.6） | `⌘⇧C 検索 URL をコピー` |
| `⌘→` | 入力に語がある | サイドパネル（詳細検索）を開き、語とスコープを引き渡して検索を起動する。パレットは閉じる（`surfaces.md` §5） | `⌘→ 詳細検索` |
| `⌘K` | 常時 | 閉じる（D-8） | 出さない |
| その他の文字 | 常時 | 入力欄へ。削除待ちを解除し、選択を先頭へ | — |

**フッターの優先順**（幅が足りないとき、右から落とす）: `↵` > `↑↓` > `⌫` > `⇥` > `⌘↵` > `⌘→` > `⌘⇧C`。`↵` は必ず残る。

**マウス**: 行のクリックは `↵` と同じ。ホバーは行を薄く強調するが**選択は動かさない**（D-7）。キーボードの選択（罫 + 太字）とホバーの強調（面だけ）は見た目で区別する。

## 7. 検索

検索は **Enter で明示的に起動**する（D-2）。打鍵ごとに API を叩かない。レートリミットの search 枠（実測 150 / 分）を
Wiki のプロジェクト並列で消費するため、暗黙の起動は成立しない（`backlog-facts.md` §3.3・§6.2）。

### 7.1 起動

- 検索行（`search`）で `↵`。または入力に一致が無く検索行しか残っていない状態で `↵`
- 範囲は現在のスコープ（§8）。`[space / project]` ならそのプロジェクト、`[space]` ならそのスペース。**根では検索しない**（D-20）
- **パレットの検索は語とスコープだけ**（D-9）。対象は課題・Wiki・ドキュメントの 3 種すべて、種別・ステータス・担当者の条件は持たない。
  条件で絞りたいときは `⌘→` でサイドパネル（詳細検索）へ渡す（`surfaces.md` §5）
- `keyword` は件名だけでなく本文とコメントにも一致する（`backlog-facts.md` §6.1）。パレット側で照合し直さない

### 7.2 起動直後の見え方

```
「ログイン」を検索                     nulab · 検索中…      ← 検索行。補足が進捗に変わる
─ 検索結果 ────────────────────── nulab 読み込み中 ─      ← セクション。補足にスペース進捗
  ◌ 検索中…                                              ← プレースホルダ行（選択がここへ移る）
─ ページ ──────────────────────────────────────────
  ▤ ログイン履歴                       スペース設定 · ページ
```

- **検索結果セクションは検索行の直下**に入る。候補セクションはその下に残る（D-3）
- 起動と同時に**選択はプレースホルダ行へ移る**。Enter の直接の結果なので I4 に反しない。最初の結果はこの行を**その場で置き換える**ので、`語 → ↵ → ↵` で先頭ヒットが開く
- 見出しの補足に種別ごとの進捗を出す: `課題 12 · Wiki 読み込み中 · ドキュメント 2`。全部揃ったら `17 件`

### 7.3 到着

- 種別（課題・Wiki・ドキュメント）単位で届く。届いた行は**選択行より下にだけ**追加する（I4）
- 並びは 一致の強さ → 更新日時の新しい順
- 選択行より上に入るべき行は**保留**する。保留があるときは検索結果セクションの先頭に `notice` 行 `N 件の新しい結果 — ↑ で先頭へ` を 1 つ出す（この行自体も選択行より上には割り込まない: 選択が先頭でないときだけ現れる）
- 保留の合流: `↑` で選択が先頭に戻ったとき、または `notice` 行で `↵`。合流後は並び直して選択は先頭
- 表示上限 30 行。超えた分は末尾の `external` 行 `他 N 件は Backlog の課題検索で`

### 7.4 進行中の入力変更

- 入力が変わったら検索結果は**即座に消す**。走っている検索は破棄し、遅れて届いた結果は捨てる
- 同じ語で再び `↵` → 同一セッション内ならキャッシュから即描画（API を叩かない）

### 7.5 0 件と障害

すべて**行**として出す。パレット全体は変えない（I6）。

| 状況 | 検索結果セクションに出す行 |
|---|---|
| 全種別が揃って 0 件 | ① `hint` 行「一致する結果がありません」 ② スコープが `[space / project]` なら `search` 行「{スペース} で検索しなおす」（アクセント） ③ `panel` 行「詳細検索で条件を変えて探す」（`⌘→` と同じ） ④ `external` 行「Backlog の課題検索を開く」。順序は **スコープ → 詳細検索 → 外部** で固定 |
| 認証切れ（401） | 結果は返らない。検索結果セクションに `status` 行「{space} は認証が切れています — 再接続」だけ |
| レート超過（429） | `status` 行「{space} は混み合っています — {reset までの秒数}秒後に再試行」。`↵` で再試行 |
| オフライン | 検索行の補足を「オフラインです。接続すると再検索します」に。候補は動く |
| 未接続のスペースへ移動しようとした（根） | そのスペースの行が `connect` 行「{space} は未接続 — 接続する」になる |

「広げれば N 件」の件数予告は**出さない**（広いスコープへの投機的リクエストになる）。

### 7.6 検索状態の URL

- `⌘⇧C` で `https://{space}/dashboard#bl-search=<base64url(JSON)>` をコピー。ペイロードは `{ v, query, scope }`。サイドパネルから
  コピーしたときは条件も含む（`surfaces.md` §5）
- 拡張を入れていない相手にも普通の Backlog ページとして開ける
- 拡張がこのフラグメントを持つページを開いたら、パレットを開いて `query` と `scope` を復元し、検索を起動する。フラグメントはページ由来の値なので**認証の選択には使わない**

## 8. スコープとコマンド階層（スタック）

MVP の裁定 D2・D3 を引き継ぐ。**スタックは 1 本**で、右端から 1 段ずつしか外せない。

```
[]                                              0 段（根）。検索せず、スペースの移動と共通ページだけ（D-20）
[nulab /]                                        1 段
[nulab / Webリニューアル /]                       2 段（開いたときの既定。現在ページから決まる）
[nulab / スペースを切り替え /]                    2 段（コマンド階層。`[space]` からだけ入れる）
```

| 操作 | 結果 |
|---|---|
| `⌫` ×2（キャレット先頭） | 右端の**スコープ**を外す。`project` → `space` → 根 |
| `Esc` / `⌫` ×1 | 右端の**コマンド**を外す。コマンドは削除待ちを経ない（外しても入力は消えず、失うものが無い） |
| 2 段階コマンドの行で `↵` | `command` セグメントを積む。リストはそのコマンドの引数だけになり、候補は混ぜない |
| 引数の行で `↵` | コマンドを実行（Phase 1 では遷移）し、閉じる |
| `space` / `project` の行で `⇥` | その段をスタックに積む（D-4）。`project` は現在のスタックが `[space]` のときだけ積める。別スペースのプロジェクトを積むときは `[space]` も一緒に置き換わる |

**不変条件**: `project` の前には `space` がある。積む操作は `⇥` と 2 段階コマンドの `↵` だけ。`command` の後に `space` / `project` は積めない。削除待ちはキー入力・スタック変更・入力変更のどれでも解除される。

スコープパスの見え方: 各段はバッジ + ラベル + `/`。右端が現在の段。削除待ちの段は取り消し線 + 警告色。幅が足りないときは左の段からラベルを畳んでバッジだけにする。

## 9. 空状態

何も打っていないときに並ぶもの。**表示キャッシュだけで即描画**し、API が要るものは後から末尾に足す。

| 順 | セクション | 中身 | 出典 | 上限 |
|---|---|---|---|---|
| 1 | 最近開いた | 課題・Wiki・ドキュメント・プロジェクト。頻度 × 直近性の順。補足に `· 最近開いた` | 表示キャッシュ + 行動ログ | 5 |
| 2 | {現在のプロジェクト} のページ | ページ定義のうち現在文脈で URL が組めるもの。よく開くページが上。「課題を開いた後はボード」のような遷移パターンはこのセクション内の並びにだけ効く（D-16） | ページ定義 | 5 |
| 3 | 担当中の課題 | 完了を除く担当課題。更新日時順 | API（届いたら追記） | 5 |

- 接続済みだが何も出せない（初回）: `hint` 行「ページ名や課題キーを入力してください」+ ページセクション
- 現在スペースが未接続: 出せるものがあればその下に `connect` 行を末尾に 1 つ。何も出せなければ `connect` 行**だけ**（説明を読ませず接続へ運ぶ）
- 根（スペースを外した後）: ① **スペース**（接続済みは `space` 行、未接続は `connect` 行。`⇥` で積む、`↵` でダッシュボードへ） ② **共通のページ**（個人設定・API キーの設定。スペース設定は admin 判定が要る可能性があり未確認、D-20）
- セクション見出しの右の補足: 最近開いたには「学習で並び替え」（学習オンのとき）、担当中の課題には件数

## 10. 接続に関わる行

| 行 | 出る場所 | `↵` |
|---|---|---|
| `connect`「このスペースを接続」 | 未接続スペースの空状態 | API キー発行ページ + 貼り付けシートへ（`surfaces.md` §1） |
| `connect`「{space} は未接続 — 接続する」 | 根のスペース一覧、空状態の末尾 | 同上（そのスペースのページを開いてから） |
| `status`「{space} は認証が切れています — 再接続」 | 検索結果の末尾 | 同上 |

接続の状態変化（接続完了・削除）はパレットを開き直したときに反映されていればよい。開いている間の同期は要らない。

## 11. トースト

コピー系コマンドと `⌘⇧C` の結果を**フッターの右端**に出す。

- 文言: `PROJ-123 をコピーしました` のように**何をコピーしたか**を含める。長い場合は 1 行で省略
- 寿命: 2 秒。次のキー入力でも消える
- コピー後にパレットは**開いたまま**（D-5）。`Esc` で閉じる
- クリップボードは拡張ページ側で書く（Service Worker からは書けない）。埋め込み側に `allow="clipboard-write"` が要る

## 12. 幅・テーマ・省略

| 幅 | 変化 |
|---|---|
| ≥ 560px | 基本 |
| 400〜560px | スコープパスは右端の段以外をバッジだけに。フッターは優先順で落とす |
| < 400px | 行の補足を隠しマーカーだけ残す。頭文字のバッジは 1 文字 |

- テーマ: `data-color-scheme="light | dark"` をルートに付け、トークンだけ再定義する。設定は「システムに追従／ライト／ダーク」。Backlog 本体がライトでもパレットはダークになりうる
- 色・寸法・書体はすべて `--bp-*` トークン経由。コンポーネントに hex・px を直書きしない
- `prefers-reduced-motion` で開閉のアニメーションを止める

## 13. IME

| 場面 | 挙動 |
|---|---|
| 変換中の `Enter` | 遷移しない。変換確定に使う（I5） |
